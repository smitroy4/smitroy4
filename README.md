## Featured Projects

### 🏠 [StayGrid](https://github.com/smitroy4/StayGrid)
> Airbnb-inspired Property Rental Platform — Spring Boot · Stripe · JWT

- Dynamic pricing engine with demand-based rate adjustments
- Stripe Webhook integration for real-time payment event handling
- Pessimistic locking to prevent double-booking race conditions
- JWT auth + Spring Security filter chain

### 🏥 [ClinixHub](https://github.com/smitroy4/ClinixHub)
> Hospital Management System — Spring Boot · Spring Security · Spring Data JPA

- JWT-based auth with role separation (Admin / Doctor / Patient)
- Appointment scheduling, billing, and patient records management
- Deployed with Docker; production-ready architecture

### 📚 [LMS-Portal](https://github.com/smitroy4/LMS-Portal)
> Learning Management System API — Spring Boot · PostgreSQL · Docker · Render

- RESTful APIs for students, courses, instructors, and enrollment management
- Clean layered architecture: Controller → Service → Repository → Entity
- Duplicate enrollment prevention with relational JPA mapping (One-to-Many, Many-to-Many)
- Containerized with Docker and **live-deployed on Render** with PostgreSQL
- Preloaded with sample data (20 students, 15 courses, 40 enrollments) for instant testing
- 🔗 [Live API](https://lms-portal-backend-lug7.onrender.com/)
